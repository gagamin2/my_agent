# Memory Management Skill

## 作用

负责维护 Agent 的长期 Memory。

Memory 是跨任务保存的长期信息，用于帮助 Agent 在未来任务中更好地理解项目和历史决策。

## 判断标准

只有满足以下条件的信息才应该进入 Memory：

- 对未来任务有帮助
- 具有长期价值
- 不容易从代码、配置或文档中直接推导出来
- 不是一次性的执行结果
- 不是临时状态

## 应该保存的信息

例如：

- 项目长期开发规范
- 重要架构决策
- 用户长期偏好
- 项目长期约定
- 对未来任务有帮助的重要历史信息

## 不应该保存的信息

例如：

- 当前任务的临时变量
- 某个文件当前有多少行
- 某次工具调用结果
- 一次性的报错
- 当前任务读取到的普通代码
- 模型的推理过程
- 临时状态

## 更新规则

如果发现值得保存的信息：

- 保留已有的重要 Memory
- 添加新的重要信息
- 删除明显过时或错误的信息
- 避免重复
- 保持 Markdown 格式
- Memory 应该简洁

如果没有值得保存的信息：

- 不修改 Memory
- 不调用 write_memory

## 权限

Memory Agent 只能维护长期 Memory。

Memory Agent 不能：

- 修改项目源代码
- 修改配置文件
- 修改测试文件
- 删除项目文件
- 操作 Memory 目录之外的文件
