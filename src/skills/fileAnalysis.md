# File Analysis Skill

## 作用

用于分析项目中的代码文件。

## 使用场景

当用户要求 Agent：

- 分析代码
- 解释文件作用
- 理解项目结构
- 总结代码逻辑

时，可以使用这个 Skill。

## 执行步骤

1. 使用 `read_file` 读取目标文件。
2. 理解文件整体结构。
3. 分析主要函数、变量和模块。
4. 总结文件的主要作用。
5. 输出结构化分析结果。

## 注意事项

- 不要修改原文件。
- 如果文件不存在，应明确告诉用户。
- 不要在没有读取文件的情况下猜测代码内容。

## 输出要求

最终输出应该包含：

1. 文件的主要作用
2. 核心结构
3. 主要函数
4. 重要执行流程
